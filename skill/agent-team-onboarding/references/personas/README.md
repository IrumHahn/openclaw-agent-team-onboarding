# 페르소나 템플릿 — 실행학교 AI 에이전트 실전 1기

에이전트는 사람처럼 대할 때 가장 효과가 납니다. 이름과 성격이 선명할수록 더 자주, 더 편하게 일을 맡기게 됩니다.

## 쓰는 법
- **A. 스킬로**: 1주차 수요일 `agent-team-onboarding` 인터뷰에서 "추천해줘"라고 하면 이 세 가지를 바탕으로 2~3안을 보여줍니다.
- **B. 수동으로**: 이 폴더(`skill/agent-team-onboarding/references/personas/`)에서 하나를 골라 `IDENTITY.md`·`SOUL.md`를 내 에이전트 워크스페이스 루트에 복사 → `[ ]` 칸을 내 것으로 채움 → `openclaw agents set-identity`.

## 모든 페르소나에 꼭 있어야 하는 5가지
1. **이름** — 부를 이름이 있어야 동료가 된다
2. **원하는 성격 3 + 반대 성격 3** — "결단력 있되 군림하지 않음"처럼 짝으로
3. **말투 예시 3줄** — 평소 보고 / 정중한 반대 / 막혔을 때 보고
4. **싫어하는 것 3** — 내가 싫어하는 말투·행동을 미리 금지
5. **경계** — 돈이 들거나 바깥을 바꾸는 일은 실행 전 확인

성격은 권한이 아닙니다. 친근한 성격이라고 메시지 발송·결제를 스스로 해도 된다는 뜻이 아닙니다.
