# 업무 지도 모드 (과제1 — 에이전트를 만들지 않음)

"내 업무 지도 만들어줘" 같은 요청일 때만 이 문서를 따른다. 팀 모드 0~6단계는 하지 않는다.

## 절대 하지 않는 것

- `openclaw agents add`, `set-identity`, `config set/patch` 등 **어떤 설정 변경도** 하지 않는다.
- `IDENTITY.md`·`SOUL.md`·`AGENTS.md`·`USER.md`를 고치지 않는다. 이름·성격(페르소나)은 과제2에서 정한다.
- 쓰는 파일은 main 워크스페이스 루트의 `my-work-map.md` **하나**뿐이다.

## 1. 5문항 인터뷰 (한 번에 보여주고, 나눠 답해도 됨)

| # | 질문 | 표에 옮길 것 |
|---|---|---|
| 1 | **하는 일** — 무슨 일을 하나요? 누구를 위해? | 맥락 |
| 2 | **반복 업무** — 매일·매주 반복되는 일은? 대략 얼마나 자주? | 업무명 · 빈도 |
| 3 | **시간 많이 드는 일** — 한 번에 오래 걸리거나 쌓이면 힘든 일은? | 소요시간 |
| 4 | **맡기고 싶은 일** — AI 비서에게 가장 먼저 넘기고 싶은 일은? | 위임 희망도 높음 |
| 5 | **절대 맡기기 싫은 일** — 내가 직접 해야 하는 일·결정은? | 위임 희망도 1 · 경계 |

답이 두루뭉술하면 예시 하나만 보여준다. "미정"도 답이다. 비밀번호·키는 받지 않는다.

## 2. 업무 표 만들기

답에서 업무를 3~20개 뽑아 각 업무에 **빈도 · 소요시간 · 위임 희망도(1~5) · 필요한 연결**(메일·카톡·시트·캘린더 등, 없으면 "없음")을 채운다. 위임 희망도는 사용자에게 확인한다(4번 답은 4~5, 5번 답은 1). 표를 보여주고 고칠 곳을 받는다.

## 3. 저장

승인된 내용을 JSON으로 쓴 뒤:

```bash
node <skill-dir>/scripts/work_map.mjs preview --map <map.json>   # 쓸 위치·내용 확인
node <skill-dir>/scripts/work_map.mjs write   --map <map.json>   # main 워크스페이스/my-work-map.md
```

위치를 바꾸려면 `--workspace <절대경로>`, 프로필은 `--profile <name>`. 다시 실행하면 기존 파일을 `my-work-map.md.bak-<시각>`으로 보관하고 갱신한다.

```json
{
  "version": 1,
  "userName": "대표님",
  "answers": { "work": "...", "recurring": "...", "timeSink": "...", "delegate": "...", "neverDelegate": "..." },
  "tasks": [
    { "name": "주간 리포트", "frequency": "매주", "duration": "2시간", "delegation": 5, "connections": ["Google Sheets", "Gmail"] }
  ]
}
```

파일 맨 위에는 위임 희망도 순 **상위 3개 업무** 요약이 자동으로 들어간다. 과제2 팀 모드가 이 요약을 읽고 카드 01·02를 줄여 묻는다.

## 4. 마무리

저장 위치를 알려주고 "에이전트·성격은 아직 바꾸지 않았다. 과제2에서 '에이전트 팀 만들어줘'라고 하면 이 지도로 총괄(main)과 팀원을 제안한다"고 전한다. 수동으로 쓰고 싶은 사람에게는 `references/work-map-template.md`를 준다.
